# Changelog

## 1.5.0

- First public release.
- System and Devices pages with automatic rotation; pin a page with `input_select.lcd_page`.
- Advanced and Simple themes.
- Devices page groups every Home Assistant device by type (Lights, Power, Climate, Air, Servers, Motion, Phones).
- Global health in the header: Repairs, failing integrations, offline devices; update badge for every update entity.
- Screen on/off switch, night mode and status sensor.
- Boot, restart and shutdown screens; optional host script for the first seconds of boot.
